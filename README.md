# Laboratorio de embeddings con TensorFlow

Proyecto académico sobre transformación de texto en embeddings mediante TensorFlow y Keras.

## Contenido
- Tokenización y secuencias.
- Capa `Embedding`.
- Clasificación de reseñas IMDB.
- Entrenamiento y evaluación.
- Gráficas de precisión y pérdida.
- Inspección de la matriz de embeddings.
- Predicciones de textos nuevos.

## Cómo ejecutarlo
1. Abrir `embeddings_tensorflow.ipynb` en Google Colab.
2. Ejecutar las celdas en orden.
3. Guardar las gráficas y resultados.
4. Subir el notebook a este repositorio.

## Tecnologías
- Python
- TensorFlow / Keras
- NumPy
- Matplotlib
